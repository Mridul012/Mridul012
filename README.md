## Featured Projects

### 🧾 AI Invoice Generator
> Automates invoice creation and business analytics from raw text using AI

**Problem:** Manually creating invoices and extracting structured data from unformatted text is slow and error-prone for small businesses.

**Solution:** A MERN-stack app that feeds raw input to Google Gemini AI, extracts structured invoice data, and generates downloadable PDFs instantly.

| | |
|---|---|
| **Stack** | React (Vite), Node.js, Express, MongoDB, Gemini API, Tailwind CSS |
| **Auth** | JWT-based secure authentication |
| **Key Features** | AI data extraction · One-click PDF export · Real-time toast notifications · REST API with CORS handling |
| **Code** | [GitHub](https://github.com/Mridul012/ai-invoice-generator) 
| **Link** | [Live Demo](https://ai-invoice-generator-khaki.vercel.app/)
